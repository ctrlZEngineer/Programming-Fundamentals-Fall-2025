# 🎨 Console Graphics & Animations

This folder contains interactive console visualizer applications utilizing coordinate manipulation (`gotoRowCol`) and precise frame timing (`sleep`).

---

## 📌 Included Programs

### Task2.cpp — Animated Expanding & Contracting Rectangles
* **Description:** Draws concentric expanding rectangles frame-by-frame, followed by an automated reverse erasure routine.

### Task3.cpp — Parametric Smile Emoji

* **Description:** Renders a smiling face on the console screen using trigonometric circle formulas:

  x = r .cos(theta)
  
  y = r .sin(theta)


### Task4.cpp — Animated Hourglass Sand Simulation
* **Description:** Generates a hollow hourglass frame filled with sand particles (`*`). Upon keypress, sand particles fall toward the lower chamber frame-by-frame.

### Task5.cpp — Spiral Star Pattern Animation
* **Description:** Plots an expanding outward/inward spiral star pattern dynamically using polar-to-Cartesian coordinate mapping.
