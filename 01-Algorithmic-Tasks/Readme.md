## 📌 Included Programs

### Task1.cpp — Number-to-Words Converter (`Digits_to_Words`)
* **Description:** Accepts an integer up to 6 digits long and outputs each digit in words (e.g., `651432` $\rightarrow$ `Six Five One Four Three Two`).
* **Key Features:** Strips leading zeros on numbers under 6 digits and rejects numbers exceeding 6 digits with an error message.
* **Concepts Used:** Modulo extraction, digit processing, `switch-case` mapping, and input validation.
